Store Manager Design System

Get your design system into Figma in 5 minutes.

No coding needed. You'll click through a few menus in the Figma app and a small helper will build the whole design system for you — colors, text styles, buttons, the works.

Wait, what is this exactly?

A "design system" is basically a kit of all the colors, fonts, buttons, and pieces that make your app look consistent. You already have one — it's the PDF/HTML doc we made together.

A "Figma plugin" is just a little helper that lives inside Figma and does a job for you. The one we built for you takes the design system from the doc and puts it into Figma automatically, so designers can use those exact colors and buttons in their work.

You don't need to write any code. You just point Figma at the helper, click "run," and wait a couple seconds.

⚠️
You'll need the Figma desktop app — not the website. The helper only works inside the app you download to your Mac. If you try to do this in figma.com in your web browser, the menu we need will be greyed out. Don't worry, the file you build will work on the website afterwards — just the setup step needs the app.

Before you start — do you have these?

  • The Figma desktop app installed on your Mac (free — download here if you don't have it)
  • A free Figma account (sign up at figma.com if you haven't)
  • About 5 minutes

The 5 steps

  1. Open the Figma desktop app and create a new file

    Launch Figma on your Mac (the actual app, not the website in a browser). Once it opens, click "New design file" on the home screen. A blank canvas opens.

    Heads up: any Figma file will work — you can also open an existing one. The helper just needs some file to be open so it has somewhere to put things.

  2. Find the "Import plugin" menu

    At the very top of your Mac screen (the menu bar), click these in order:

    Menu → Plugins → Development → Import plugin from manifest…
    If "Import plugin from manifest…" is grey and you can't click it: you're probably in the website version, not the app. Close your browser, open the Figma app from your Applications folder, and try again.

  3. Pick the file called manifest.json

    A file picker window opens. You need to find a file called manifest.json on your Mac. Here's exactly where it lives:

    Full path on your Mac
    /Users/saimyothu/claude-workspace/
    Retina AI/compass-ui-ux-designs/retina/figma-plugin/
    ├── manifest.json ← pick this one
    └── code.js
    Easiest way to get there: in the file picker, press Cmd + Shift + G on your keyboard. A little box appears — paste the path above (the part with the slashes) into it and hit Enter. You'll jump straight to the right folder. Then double-click manifest.json.

  4. Run the helper

    Figma now knows about the helper. To actually run it, click through these menus the same way as before:

    Menu → Plugins → Development → Store Manager — Design System Builder

    Click that last one. You won't see a popup or window — it just starts working quietly.

  5. Wait about 2 seconds — and you're done

    After a moment, a new page called "Store Manager — Design System" appears in your Figma file. The view zooms in on a cover page automatically. Scroll around and you'll see all the colors, fonts, buttons, and screen examples laid out for you.

    To save and share it: Figma saves automatically. To share with someone, click the blue "Share" button in the top-right of Figma and either invite them by email or copy a link.

Something went wrong?

The "Import plugin from manifest…" menu item is greyed out

You're almost certainly in the browser version of Figma. The "Development" menu only shows up in the desktop app. Quit your browser, open Figma from your Applications folder (or download it from figma.com/downloads), and try again.

I can't find the manifest.json file

In the file picker, press Cmd + Shift + G to open a "Go to folder" box. Paste this into it:

/Users/saimyothu/claude-workspace/Retina AI/compass-ui-ux-designs/retina/figma-plugin/

Hit Enter. You'll see manifest.json — double-click it.

The fonts look wrong or boxy after the helper runs

The design system uses two free fonts: Inter and JetBrains Mono. If you don't have them installed on your Mac, Figma will substitute something else and it'll look off. Download them free from fonts.google.com (search the names), install both, restart Figma, and run the helper again.

I ran it twice and now there are duplicate pages

That's normal — each run creates a fresh new page so you can compare or pick the best one. To delete an old one, right-click the page name in the left sidebar of Figma and choose "Delete page."

It says variables didn't get created

"Variables" is a Figma feature that needs a paid plan (Professional or higher). If you're on the free plan, the colors and fonts still get built as regular styles — designers can still use them, they just won't be in the fancier "variables" format. No action needed unless you specifically want variables.
